# eggswap README honesty audit

Scope: `eggswap/README.md` (85 lines) checked line-by-line against
`eggswap/core/types.py`, `eggswap/core/select.py`, `eggswap/core/store.py`,
`eggswap/adapters/claude_cswap.py`, `eggswap/adapters/codex_home.py`,
`eggswap/cli.py`, `eggswap/pyproject.toml`, `eggswap/NOTICE`, and the
`test_eggswap_*` files under `tests/`. Grades: TRUE / MISLEADING / FALSE /
UNVERIFIABLE.

## Claim table

| 1 | "rotates BOTH Claude and Codex accounts behind a single interface" (L3-4) | MISLEADING | `core/select.py` `rank()`/`select()` are pure functions of their arguments with **no persisted state across calls** (comment at select.py:97-99: "round-robin degrades to a stable, documented order... rather than faking rotation with a counter nothing keeps between invocations"). There is no call site anywhere in `cli.py` that invokes `LeaseStore` from `select`. What exists is *headroom-ranked selection*, re-run fresh each call; "rotates" reads to a stranger as automatic round-robin cycling through accounts over time, which nothing in the code does. `Policy.prefer="round_robin"` is a real option name but literally cannot rotate without cross-call memory. |

## Edits that would turn every MISLEADING/FALSE row TRUE

1. **Row 1/2/17 (rotation, parity)** — Reword the opening paragraph. Replace "rotates BOTH Claude and Codex accounts" with something like: *"selects, on request, the best available account of either provider — Claude today has a real capacity signal across all configured accounts; Codex does not yet (see 'State of the project')."* Do not use the word "rotates" unqualified until `select` either (a) persists last-chosen state so `round_robin` is real, or (b) is wired into an automatic retry-on-exhaustion loop. Until then, say "selects" or "picks", not "rotates".
2. **Row 14 (Lease not wired into `run`)** — Either (a) wire `_cmd_run` to call `LeaseStore.acquire()`/`.release()` around the launch so the sentence becomes true, or (b) if that's intentionally out of scope for this milestone, change L47-49 to something like: *"`Lease` (`core/store.py`) provides the exclusive-fencing primitive `run` will use; the CLI does not yet call it, so concurrent `run` invocations against the same profile are not yet fenced — see Issue #581."* Shipping the current sentence unedited is the single highest-value fix in this audit: it's a safety claim (exclusive hold prevents the #581 credential-corruption failure) that the code does not currently deliver.
3. **Row 13 (`run` usage)** — Add the actual usage shape to the Commands block, e.g. `eggswap run <profile-key> [--dry-run] [-- <child args>]`, since the parser requires a profile-key positional that the one-line description omits.
4. Optional, low-priority: in the NOTICE, add one clause explicitly stating that the `Available`/`Exhausted`/`AuthDead`/`Unknown` sealed union and the fencing `Lease` model are eggswap's own design, not derived from claude-swap, to close the only ambiguity a careful reader might have between "shape of a quota model" (borrowed) and "the honesty contract" (not borrowed).
